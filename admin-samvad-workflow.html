अधिकारी नियुक्ति

पहले से पंजीकृत SBPF सदस्य चुनें। नियुक्ति के बाद वही सदस्य चुने गए स्तर के अधिकार से काम करेगा।

नियुक्ति केवल Admin की कार्रवाई से होगी।

PIN Code एवं क्षेत्र मैपिंग

Admin द्वारा सत्यापित PIN Code को सक्रिय क्षेत्र से जोड़ा जाएगा।

कोई PIN Code स्वतः नहीं जोड़ा गया है।
