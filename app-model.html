शिक्षा कार्यक्षेत्र

स्वर्णिम गुरुकुलम के लिए उपलब्ध categories, content, resources और teacher workflow।

ई-लाइब्रेरीवीडियो/लिंकप्रतियोगी परीक्षाशिक्षक सामग्री

शिक्षा सामग्री के लिए सार्वजनिक पढ़ने की अनुमति और प्रकाशित रिकॉर्ड आवश्यक हैं; निजी विद्यार्थी डेटा वेबसाइट पर नहीं दिखाया जाएगा।

मीडिया और सामग्री

समाचार, वीडियो, अभियान सामग्री और पोस्ट — वास्तविक प्रकाशित डेटा मिलने पर ही प्रदर्शित होंगे।

समाचारnews table — सार्वजनिक published रिकॉर्ड होने पर
वीडियोvideos table — सार्वजनिक published रिकॉर्ड होने पर
अभियान सामग्रीcampaign_content / work_area_content — अनुमत सार्वजनिक सामग्री

डेटा और वर्कफ़्लो मॉडल

यह मैप उपलब्ध schema और Edge Function सूची पर आधारित है, हर प्रक्रिया का end-to-end परीक्षण नहीं।

1️⃣

सदस्यता

Admin-निर्मित सदस्य → login → profile → KYC → ID/certificate → भुगतान सत्यापन।

2️⃣

शिकायत / संवाद

शिकायत प्राप्ति → पिनकोड/क्षेत्र मिलान → अधिकारी/कार्रवाई → स्थिति अपडेट/एस्केलेशन।

3️⃣

शिक्षा

शिक्षक/एडमिन सामग्री → समीक्षा/अनुमोदन → प्रकाशित संसाधन → विद्यार्थी पहुँच।

4️⃣

सरकारी योजनाएँ

स्रोत/सिंक → रिकॉर्ड सत्यापन → प्रकाशित योजना → सार्वजनिक वेबसाइट सूची।

5️⃣

सेवा अनुरोध

अनुरोध → असाइनमेंट → अपडेट → फीडबैक; वास्तविक स्थिति डेटाबेस से पढ़ें।

6️⃣

EMS / HMS

स्कूल/अस्पताल tenant → अधिकृत user → role-आधारित रिकॉर्ड; कोई निजी स्वास्थ्य/छात्र डेटा सार्वजनिक नहीं।

7️⃣

AI सहायता

सवाल → सार्वजनिक curated knowledge/live public records → उत्तर; OPENAI_API_KEY सर्वर पर ही रहे।

8️⃣

ऑटोमेशन

automation_rules → निर्धारित/ट्रिगर रन → लॉग/स्थिति; cron और वास्तविक execution अलग से सत्यापित करें।

सुरक्षा: इस सार्वजनिक मॉडल में service-role key, KYC, निजी सदस्य रिकॉर्ड, मरीज डेटा, वेतन, भुगतान टोकन या audit details embed नहीं हैं।
